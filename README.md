# CodeAlpha Python Internship

This repository contains the Python projects completed during my CodeAlpha Internship.

## Tasks

### Task 1 - Hangman Game

A simple command-line Hangman game developed using Python.

**Features:**
- Random word selection
- Letter-by-letter guessing
- Tracks incorrect guesses
- Prevents repeated guesses
- Displays win and lose messages

**File:** `Task-1-Hangman/hangman.py`

### Task 2 - Stock Portfolio Tracker

A command-line Stock Portfolio Tracker developed using Python.

**Features:**
- Displays available stocks and prices
- Accepts stock name and quantity
- Calculates investment for each stock
- Calculates total investment
- Handles invalid stock names

**File:** `Task-2-Stock-Portfolio/stock_portfolio.py`

## Task 3 - Email Address Extractor

A Python program that extracts email addresses from a text file using regular expressions.

### Features:

- Reads text from an input file
- Finds email addresses automatically
- Saves extracted emails to an output file
- Displays the extracted email addresses
- Uses Python's `re` module

**Files:**
`Task-3-Email-Extractor/email_extractor.py`

**Input:** `Task-3-Email-Extractor/sample.txt`

Output: `Task-3-Email-Extractor/extracted_emails.txt`
